# Glosario

Asignar colaborador
:   Opción de la Principal del banco de datos para darle a otra persona acceso a tu banco. Esa persona trabaja con el rol «Colaborador banco de datos de actividades CyT».

Banco de datos
:   Nombre que SIGEVA da a tu CV estructurado. Se carga con el rol «Usuario banco de datos de actividades de CyT».

Barra negra
:   Franja debajo del menú superior con las pantallas de cada solapa. La pantalla abierta aparece resaltada en naranja.

Código del trámite
:   Código que te pasa quien es titular de un trámite (por ejemplo, la dirección de un proyecto) para que te incorpores desde la solapa **Trámite** del banco de datos.

Compartir formularios
:   Operación que se hace en el sistema de origen para que otro sistema pueda importar tus datos. Desde SIGEVA-UNC, el único destino posible es CONICET. Usa una contraseña propia de la operación y autoriza la importación de forma permanente.

CONEAU Global
:   Sistema de la Comisión Nacional de Evaluación y Acreditación Universitaria. Toma los datos de CVar (por ejemplo, para la ficha docente).

Convocatorias vigentes
:   Pantalla del rol «Usuario presentación/solicitud» con las convocatorias abiertas, agrupadas por tipo, cada una con su botón **Postular**.

CVar
:   Registro unificado de CV del sistema científico nacional. Recibe datos de SIGEVA-CONICET.

CV adjunto
:   Archivo con tu CV que se sube en Otros anteced. › Currículum, además de los datos estructurados.

Derecho de exclusión (OPT-OUT)
:   Opción de cada publicación y desarrollo para pedir que su texto completo no pase al repositorio institucional, cuando hay confidencialidad, trámites de propiedad industrial o acuerdos previos con terceros (Ley 26.899).

DOI
:   Identificador permanente de un documento digital, como un artículo. Permite la precarga del artículo en SIGEVA.

En prensa
:   Trabajo aceptado para publicación que todavía no salió. Se carga con un .zip que reúne la publicación y la constancia de que está en prensa.

Estado
:   Columna de la Principal del banco de datos para los ítems de registro único («Con datos» o «Sin datos»), y de la Principal de un trámite para cada formulario («Ok» o «Sin Datos»).

Experticia en CyT
:   Parte de Datos personales donde resumís tu perfil, tus áreas y líneas de investigación y tus palabras clave.

Foto (del banco de datos)
:   Copia de tu banco de datos que el sistema toma cuando te incorporás a un trámite. Los cambios posteriores sirven para futuras presentaciones, pero no se reflejan en ese trámite.

Importar
:   Botón de cada ítem del CV que trae los registros compartidos desde otro sistema. No todos los ítems lo tienen.

ISBN
:   Número internacional que identifica un libro. Es obligatorio en Libros y en Partes de libros.

ISSN / e-ISSN
:   Número internacional que identifica una publicación periódica, impresa o electrónica. Tiene ocho caracteres con un guion (`1234-5678`).

Post print / Versión final
:   Tipos de archivo que SIGEVA pide elegir al adjuntar el texto completo de un artículo. Post print suele designar la versión aceptada después de la revisión por pares. Cuál conviene elegir está planteado para decidir en [Publicaciones](cv/produccion-cientifica.md).

Precarga de artículos
:   Pantalla que aparece al crear un artículo: con el DOI o el ISSN completa parte de los datos. Con **Omitir** se sigue a mano.

Principal
:   Pantalla inicial de cada rol. En el banco de datos, resume todas las secciones del CV con su estado o su cantidad de registros.

Referato
:   Evaluación por pares de un trabajo antes de publicarlo.

Rol
:   Perfil con el que trabajás en SIGEVA. Toda cuenta tiene tres: banco de datos, presentación/solicitud y colaborador. Según la función, puede haber otros, como miembro de comisión.

Situación de revista
:   Condición y jerarquía de un cargo docente (por ejemplo, ayudante interino o adjunto regular). Si cambia, se carga un cargo nuevo.

SIGEVA
:   Sistema Integral de Gestión y Evaluación, desarrollado por el CONICET. La UNC tiene su propia instalación: <https://sigeva.unc.edu.ar>.

SIGEVA-CONICET
:   Instalación del CONICET. Funciona como puente entre los SIGEVA de las universidades y hacia CVar.
