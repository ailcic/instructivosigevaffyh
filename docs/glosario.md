# Glosario

Banco de datos
:   Nombre que SIGEVA da a tu CV estructurado. Se carga con el rol «Usuario banco de datos de actividades de CyT».

Compartir formularios
:   Operación que se hace en el sistema de origen para habilitar que otro SIGEVA, o CVar, importe tus datos. Usa una contraseña propia de la operación.

CONEAU Global
:   Sistema de la Comisión Nacional de Evaluación y Acreditación Universitaria. Toma los datos de CVar (por ejemplo, para la ficha docente).

CVar
:   Registro unificado de CV del sistema científico nacional. Recibe datos de SIGEVA-CONICET.

Derecho de exclusión
:   Opción de cada publicación para pedir que su texto completo no se difunda en el repositorio institucional, cuando hay acuerdos de confidencialidad, trámites de propiedad industrial o acuerdos con terceros (Ley 26.899).

DOI
:   Identificador permanente de un documento digital, como un artículo. Permite la precarga del artículo en SIGEVA.

En prensa
:   Trabajo aceptado para publicación que todavía no salió. Se carga con la constancia de aceptación.

Experticia en CyT
:   Parte de Datos personales donde resumís tu perfil, tus áreas y tus palabras clave.

Foto (del banco de datos)
:   Copia de tu banco de datos que el sistema guarda al enviar una presentación o al asociarte a un proyecto. Los cambios posteriores no la modifican.

Importar
:   Botón de cada ítem del CV que trae los registros compartidos desde otro sistema.

ISBN
:   Número internacional que identifica un libro.

ISSN / e-ISSN
:   Número internacional que identifica una publicación periódica, impresa o electrónica. Tiene ocho caracteres con un guion (`1234-5678`).

Postprint / versión final
:   Versiones del texto de una publicación. Postprint suele designar la versión aceptada después de la revisión por pares. SIGEVA pide indicar qué versión adjuntás.

Precarga de artículos
:   Ventana que aparece al crear un artículo: con el DOI o el ISSN completa parte de los datos. Con **Omitir** se sigue a mano.

Referato
:   Evaluación por pares de un trabajo antes de publicarlo.

Rol
:   Perfil con el que trabajás en SIGEVA: banco de datos, presentación/solicitud o miembro de comisión.

Situación de revista
:   Condición y jerarquía de un cargo docente (por ejemplo, ayudante interino o adjunto regular). Si cambia, se carga un cargo nuevo.

SIGEVA
:   Sistema Integral de Gestión y Evaluación, desarrollado por el CONICET. La UNC tiene su propia instalación: <https://sigeva.unc.edu.ar>.

SIGEVA-CONICET
:   Instalación del CONICET. Funciona como puente entre los SIGEVA de las universidades y hacia CVar.
