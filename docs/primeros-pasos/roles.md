# Roles

Al ingresar, SIGEVA te pide elegir un rol. El rol define qué parte del sistema vas a ver.

!!! note "Pendiente de verificar"
    La pantalla de selección de roles no se relevó. La descripción de los dos primeros roles proviene del instructivo de la UNC y del manual de la UBA. El rol de colaborador sí se vio dentro del sistema.

## Usuario banco de datos de actividades de CyT

Es el rol para cargar y actualizar tu currículum. Con él también podés:

- [compartir tus formularios](../sincronizacion/index.md) con SIGEVA-CONICET e importar datos;
- [incorporarte a un trámite](../proyectos-y-tramites/index.md) con un código;
- [asignar un colaborador](#colaborador);
- [imprimir tu CV](../cv/adjunto-impresion.md).

Todo el capítulo «Banco de datos» de esta guía se hace con este rol.

## Usuario presentación/solicitud

Es el rol para postularte a una convocatoria. El instructivo de la UNC lo describe para los concursos docentes: se elige la convocatoria, se completa lo propio de la presentación y se envía. Esta guía todavía no lo cubre.

## Colaborador

En **Principal → Asignar colaborador** podés autorizar a otra persona a trabajar sobre tu banco de datos. La pantalla muestra una tabla con las columnas **Rol**, **Apellido y nombre**, **Cuil** y **Fecha alta**, el enlace **Nuevo** para agregar un colaborador y, por cada fila, **Ver** y **Borrar**. El rol que el sistema asigna se llama **Colaborador banco de datos de actividades CyT**.

!!! note "Pendiente de verificar"
    No se abrió el formulario de alta de colaborador ni se comprobó qué puede hacer exactamente la persona designada. La guía de sincronización del CONICET indica que un colaborador también puede sincronizar datos.

!!! tip "Sugerencia de la SeICyT"
    Un colaborador puede modificar tu currículum. Designá solo a personas de confianza y dalas de baja con **Borrar** cuando terminen la tarea.
